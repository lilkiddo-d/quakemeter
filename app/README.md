# Quakemeter app

Next.js (App Router) frontend for Quakemeter: the QVIX realized-volatility index, QVIX futures, the LP vault, variance swaps and (optionally) $QUAK staking on Robinhood Chain.

Stack: Next.js 16, wagmi 2, viem 2, RainbowKit 2, TanStack Query, Tailwind CSS 4, lightweight-charts.

## Environment variables

All optional. See `.env.example`, and copy it to `.env.local` for local work.

| Variable | Default | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_CHAIN_ID` | `4663` | `4663` = Robinhood Chain mainnet, `31337` = local anvil fork |
| `NEXT_PUBLIC_RPC_URL` | from `config/chains.json` (4663) / `http://127.0.0.1:8545` (31337) | RPC override |
| `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` | empty | Empty means injected browser wallets only, with no WalletConnect |
| `NEXT_PUBLIC_PROJECT_TOKEN` | empty | $QUAK token address. Empty hides all token features (Stake page, fee discounts) |
| `NEXT_PUBLIC_GEOBLOCK_COUNTRIES` | empty | Comma-separated ISO country codes redirected to `/blocked`, using Vercel's `x-vercel-ip-country` header |

`NEXT_PUBLIC_*` values are inlined at build time, so you have to rebuild after changing them.

## Data sources

- Chain config is imported directly from `../config/chains.json`, the single source of truth. The import goes through the `@config/*` path alias, `turbopack.root` and `experimental.externalDir`.
- Contract ABIs live in `src/abi/*.ts`. They are generated by `node scripts/export-abis.mjs` at the repo root, so don't edit them.
- Deployment addresses come from `src/config/generated/deployments.<chainId>.json`, which the deploy script writes. `scripts/gen-deployments.mjs` runs automatically before `dev`, `build` and `lint`. It bundles whatever files exist into `src/config/deployments.generated.ts`, which is gitignored. If none exist, the UI shows "Contracts not deployed on this network yet".

## Development

```bash
pnpm install                      # at the repo root
pnpm --filter quakemeter-app dev  # http://localhost:3000
```

To run against a local anvil fork:

```bash
anvil --fork-url https://rpc.mainnet.chain.robinhood.com --chain-id 31337
# deploy the contracts to the fork (writes app/src/config/generated/deployments.31337.json)
NEXT_PUBLIC_CHAIN_ID=31337 pnpm --filter quakemeter-app dev
```

## Build and checks

```bash
pnpm --filter quakemeter-app build
pnpm --filter quakemeter-app lint   # tsc --noEmit
```

## Deploy to Vercel

- Root Directory: `app`. Keep "Include files outside the root directory" enabled, which is the default, because the app reads `../config`.
- Install Command: `pnpm install`
- Build Command: `pnpm build`
- Set the environment variables above in the Vercel project settings.
- Commit `src/config/generated/deployments.4663.json` so that production builds pick up the mainnet addresses.
